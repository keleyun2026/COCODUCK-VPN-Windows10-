🧩 二、使用 Clash Verge 第三方客户端

如果你习惯使用 Clash 系列客户端，也可以通过 COCODUCK 提供的第三方客户端配置进行连接。

1. 购买 COCODUCK 套餐

首先访问 COCODUCK 官方网站 [https://www.cocoduck.site/](https://www.cocoduck.site/auth/register?code=1d42b121f4)，注册账号并购买适合自己的套餐。

请确保账号已购买有效套餐，以便获取对应的订阅配置。

2. 下载 Clash Verge

登录 COCODUCK 官网后台，在用户面板中找到：

第三方客户端 → Clash Verge

点击进入后，根据页面提供的下载说明获取客户端。

也可以通过以下页面下载：

https://sites.google.com/view/zhuanxianjichang/fqtool/clash-verge

建议优先使用官网后台提供的下载入口，并留意客户端版本与 Windows 系统的兼容性。

3. 获取订阅配置

安装 Clash Verge 后：

登录 COCODUCK 官网。
进入用户后台面板。
找到「第三方客户端」。
点击「Clash Verge」。
按照页面说明获取适用于 Clash Verge 的订阅配置。

4. 导入订阅

打开 Clash Verge，根据客户端界面提示添加订阅配置。

如果官网提供订阅链接，可以按照客户端的订阅导入说明粘贴链接并保存。

5. 选择配置并连接

订阅更新成功后：

进入配置页面。
选择已经导入的配置。
根据需要选择可用节点。
按照客户端提示开启系统代理。
确认连接状态正常后即可使用。
注意：Clash Verge 不同版本的界面可能略有区别，请以实际客户端界面为准。

❓ 四、常见问题 FAQ

Q1：COCODUCK Windows 客户端支持 Windows 10 吗？

支持。本指南提供 Windows 10 客户端下载入口。建议保持系统更新，并确保满足客户端安装要求。

Q2：官方 Windows 客户端需要手动导入订阅吗？

不需要。根据官方提供的使用方式，下载安装客户端后，登录账号即可一键使用。

Q3：没有购买套餐可以使用吗？

请先在 COCODUCK 官网购买适合自己的套餐，再登录客户端使用对应服务。

Q4：Clash Verge 和官方客户端有什么区别？

官方客户端主打简单便捷，登录后即可使用；Clash Verge 则需要用户自行导入订阅和进行相关配置。

Q5：客户端无法连接怎么办？

可以尝试以下方法：

检查网络连接是否正常。
确认 COCODUCK 账号是否登录成功。
检查套餐是否处于有效状态。
重新启动客户端。
如果使用 Clash Verge，检查订阅是否更新成功。
检查 Windows 防火墙或其他安全软件是否影响客户端运行。

如果问题仍然存在，建议联系 COCODUCK 官方客服寻求帮助。
